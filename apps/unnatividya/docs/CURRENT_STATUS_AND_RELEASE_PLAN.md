## Delivery order

1. **Release accuracy and safe deployment:** identify the VPS commit and current website migration state; validate the intended Git diff and local CI; back up the website database; deploy using one runbook; check lead capture, article URLs, sitemaps, admin access, analytics and Caddy redirects. No VPS action has been taken as part of this documentation update.
2. **Publish reviewed facts:** inspect the 30-course publishing checklist; resolve the Amity awarding-entity and January 2027 period questions; review category fees, the MAJMC correction, eligibility and curriculum proposals; apply only approved items. Track published counts, not just prepared counts.
3. **Trust and operational hardening:** substantiate or qualify prominent owner-stated claims; complete real email and external CRM delivery checks; migrate the website from end-of-life Node 20 to a supported LTS line after compatibility testing. [Node release status](https://nodejs.org/en/about/previous-releases).
4. **Learner tools and content:** follow the [page-by-page content and UI expansion plan](CONTENT_AND_UI_EXPANSION_PLAN.md), starting with MBA course pages across the three universities and their university profiles; publish reviewed eligibility rules and activate the [weekly source evidence checks](WEEKLY_SOURCE_CHECKS_2026-10-09.md) after deployment. The free source-bounded Groq recommender, category-aware cost planner and eligibility checker are implemented locally; their VPS checks and reviewed CMS facts remain. Guides still need a CMS workflow: increment 76 delivered the **blog article** editor, not guide editing. Keep all 26 articles and 101 specialization URLs under the owner's existing decisions while improving them; any merge/noindex change requires a new decision.
5. **Measure and iterate:** verify Search Console and Bing properties, submit the sitemap index, inspect representative URLs, check GA4 events and review actual indexing, queries and page experience. Good metadata or schema cannot guarantee ranking. [Google SEO guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide).

The process-local last-good catalog/article fallback and website CI were implemented in increment 76. A **persistent** snapshot across restarts, cross-request caching, rendered draft previews, scheduled publishing, shared rate limits and smaller image/runtime work remain open. GA4-only supersedes earlier GTM recommendations.
