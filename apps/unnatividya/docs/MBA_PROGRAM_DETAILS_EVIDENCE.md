The four optional CMS blocks are `programDetails.study`, `assessment`, `additionalCharges` and `specialization`. Each stores its own `scope`, `sourceUrl`, `checkedAt` and concise points. The [prepared data](../src/data/prepared-program-details.json) is available through the **Load prepared program details** control on each MBA's Catalog revisions page. Loading changes only the unsaved proposal. Once reviewed and submitted, an administrator can use the [bulk publish action](CMS_PUBLISHING_DEPLOYMENT.md) to apply ready revisions. Missing blocks stay as explicit questions on the public course page.

No new university profile claims, numerical fee changes, intake deadlines or recognition statuses are proposed here. The next content pass should resolve category-specific eligibility, total payable and refund/document requirements from official PDFs or current university policy pages before filling those sections.
